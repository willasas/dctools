# AI文件管理工具

## 项目概述

本项目是一个多功能的AI文件管理工具，主要用于批量处理和组织文件，包括文件去重、重命名、小说文件智能重命名、Excel清单导出等功能。工具提供了图形用户界面（GUI）和命令行界面（CLI）两种操作方式，方便用户灵活使用。

## 功能介绍

### 1. 批量创建文件夹

**功能描述**：根据指定规则批量创建文件夹。

**主要特点**：
- 支持自定义文件夹名称列表
- 支持序号递增命名
- 支持拼音转换

### 2. 批量重命名文件

**功能描述**：按照指定规则批量重命名文件。

**主要特点**：
- **多种命名规则**：支持自定义命名规则，包括前缀、后缀、时间戳等。
- **拼音转换**：自动将中文转换为拼音，方便国际化。
- **序号管理**：支持自定义起始序号和增量。
- **实时预览**：在重命名前预览新文件名，确保命名的正确性。

### 3. 小说文件重命名（新增）

**功能描述**：智能识别txt小说文件中的书名和作者信息，自动重命名为标准格式。

**主要特点**：
- **智能识别**：自动从文件内容中提取书名和作者信息
- **支持多种格式**：
  - 单行格式：`书名:xxx作者:xxx`
  - 两行格式：`书名:xxx` 和 `作者:xxx`
  - 文件名格式：`书名 作者：xxx.txt`
  - 标准格式：`《书名》作者.txt`
- **多线程处理**：使用多线程处理大量文件，提高处理速度
- **自动跳过**：自动跳过已正确命名的文件
- **智能处理**：无法识别时使用原文件名作为书名
- **安全复制**：复制文件而非移动，避免数据丢失
- **独立输出**：支持将重命名后的文件保存到独立文件夹

**支持的书名/作者标记**：
- 书名标记：`书名：xxx`、`书名 xxx`、`【书名】`、`《书名》`
- 作者标记：`作者：xxx`、`作者 xxx`、`by xxx`、`作者名：xxx`

### 4. 删除重复文件

**功能描述**：检测并删除重复文件，支持多种去重方式。

**主要特点**：
- **多种去重方式**：支持按哈希值、文件名、文件大小和修改时间去重。
- **多线程处理**：使用多线程计算哈希值，提高处理速度。
- **重复文件预览**：在删除前预览重复文件，确保操作的准确性。
- **自定义保留规则**：支持保留第一个、最后一个或最大的文件。

### 5. 导出Excel清单

**功能描述**：将文件夹中的文件列表导出为Excel格式。

**主要特点**：
- 支持导出文件名、大小、修改时间等信息
- 支持自定义导出字段
- 支持多级文件夹递归扫描

### 6. 分析文件夹信息

**功能描述**：分析文件夹的大小、文件数量等信息。

**主要特点**：
- 统计文件总数和文件夹总数
- 计算文件夹大小
- 支持按文件类型统计

### 7. 媒体属性编辑

**功能描述**：编辑媒体文件的属性信息。

**主要特点**：
- 支持图片、音频、视频文件
- 编辑元数据信息

### 8. 批量自动化

**功能描述**：批量处理文件，包括去重、重命名和移动操作。

**主要特点**：
- **文件夹选择**：用户可以自由选择源文件夹和目标文件夹。
- **文件夹映射管理**：支持自定义文件夹映射，将源文件夹映射到目标文件夹。
- **去重功能**：自动检测并删除重复文件，展示重复文件组。
- **重命名规则**：按照指定规则重命名文件，保持文件名的一致性。
- **边处理边去重**：在移动文件前检查目标文件是否存在，避免重复移动。
- **处理日志**：实时显示处理过程、进度和报错信息。

### 9. 启动GUI界面

**功能描述**：启动图形用户界面，提供更直观的操作方式。

## 安装说明

### 环境要求

- Python 3.7+
- tkinter（Python标准库）
- tkinterdnd2（拖拽功能）
- 其他依赖包（见requirements.txt）

### 安装步骤

1. 克隆或下载项目到本地
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行主程序：
   ```bash
   python main.py
   ```

## 使用指南

### 命令行操作

运行 `python main.py` 后，选择对应功能编号：

```
功能列表:
  1. 批量创建文件夹
  2. 批量重命名文件
  3. 小说文件重命名
  4. 删除重复文件
  5. 导出Excel清单
  6. 分析文件夹信息
  7. 媒体属性编辑
  8. 批量自动化
  9. 启动GUI界面
  0. 退出程序
```

### 小说文件重命名使用步骤（GUI）

1. **选择文件夹**：
   - 点击"浏览"按钮选择源文件夹（包含小说txt文件的文件夹）。
   - 点击"浏览"按钮选择输出文件夹（重命名后文件的保存位置）。
   - 可选：勾选"使用源文件夹"将文件保存在原位置。

2. **设置选项**：
   - 勾选"跳过已正确命名的文件"可自动跳过格式正确的文件。

3. **预览结果**：
   - 点击"预览"按钮查看所有文件的处理结果。
   - 查看统计信息：总数、待重命名、跳过、无法识别、错误。

4. **执行重命名**：
   - 点击"执行重命名"按钮开始处理。
   - 处理完成后会显示详细的处理结果。

### 小说文件重命名使用步骤（CLI）

```bash
✅ 书名:三体作者:刘慈欣.txt -> 《三体》刘慈欣.txt
...
```

### 批量自动化使用步骤

1. **选择文件夹**：
   - 点击"浏览"按钮选择源文件夹（包含待处理文件的文件夹）。
   - 点击"浏览"按钮选择目标文件夹（处理后文件的保存位置）。

2. **管理文件夹映射**：
   - 查看默认映射：程序会加载默认的文件夹映射。
   - 添加映射：点击"添加映射"按钮，输入源文件夹和目标文件夹名称。
   - 编辑映射：选择现有映射，点击"编辑映射"按钮修改。
   - 删除映射：选择现有映射，点击"删除映射"按钮删除。
   - 保存映射：点击"保存映射"按钮保存更改。

3. **开始处理**：
   - 点击"开始处理"按钮开始批量处理文件。
   - 处理过程中，日志区域会显示处理进度和结果。

4. **预览处理**：
   - 点击"预览"按钮可以预览处理结果，而不实际执行操作。

### 重复文件删除使用步骤

1. **选择文件夹**：选择要检查重复文件的文件夹。
2. **选择去重方式**：选择按哈希值、文件名、文件大小或修改时间去重。
3. **设置保留规则**：选择保留第一个、最后一个或最大的文件。
4. **预览重复文件**：点击"预览重复文件"按钮查看重复文件。
5. **删除重复文件**：点击"删除重复文件"按钮删除重复文件。

### 批量重命名使用步骤

1. **选择文件夹**：选择要重命名文件的文件夹。
2. **设置参数**：
   - 输入中文名称（用于生成拼音）。
   - 设置起始序号和增量。
   - 选择命名规则。
3. **预览重命名**：点击"预览重命名"按钮查看新文件名。
4. **执行重命名**：点击"执行重命名"按钮执行重命名操作。

## 配置说明

### 文件夹映射配置

文件夹映射存储在 `config/folder_mapping.json` 文件中，格式为 JSON：

```json
{
  "源文件夹名称": "目标文件夹名称",
  "陆雪琪": "L_陆雪琪",
  "云望舒": "Y_云望舒"
}
```

用户可以通过 GUI 界面管理映射，也可以直接编辑此文件。

### 日志配置

日志文件存储在 `logs` 目录中，包含处理过程的详细信息。

## 常见问题

1. **Q: 小说文件重命名后出现乱码怎么办？**
   A: 确保文件编码为UTF-8格式，程序会自动处理常见的编码问题。

2. **Q: 如何处理无法识别书名和作者的文件？**
   A: 程序会自动使用原文件名作为书名，作者显示为"作者：不详"。

3. **Q: 处理过程中出现错误怎么办？**
   A: 查看日志区域的错误信息，根据错误提示进行排查。

4. **Q: 如何添加新的文件夹映射？**
   A: 在批量自动化面板中点击"添加映射"按钮，输入源文件夹和目标文件夹名称。

5. **Q: 去重后文件没有被删除怎么办？**
   A: 检查是否有足够的权限，或者文件是否被其他程序占用。

6. **Q: 重命名后的文件格式不符合预期怎么办？**
   A: 检查命名规则设置，确保规则正确。

7. **Q: 程序运行缓慢怎么办？**
   A: 对于大量文件的处理，可能会需要较长时间，请耐心等待。小说文件重命名功能已使用多线程优化。

## 注意事项

- **备份重要文件**：在执行批量操作前，请备份重要文件，以防意外发生。
- **权限问题**：确保程序有足够的权限访问和修改文件。
- **文件占用**：确保待处理的文件没有被其他程序占用。
- **存储空间**：确保目标文件夹有足够的存储空间。
- **编码问题**：建议使用UTF-8编码的txt文件以获得最佳识别效果。
