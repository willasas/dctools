# 资源管理工具

## 项目概述

本项目是一个资源管理工具，主要用于批量处理和组织文件，包括文件去重、重命名和移动等功能。工具提供了图形用户界面（GUI），方便用户直观地操作。

## 功能介绍

### 1. 批量自动化

**功能描述**：批量处理文件，包括去重、重命名和移动操作。

**主要特点**：
- **文件夹选择**：用户可以自由选择源文件夹和目标文件夹。
- **文件夹映射管理**：支持自定义文件夹映射，将源文件夹映射到目标文件夹。
- **去重功能**：自动检测并删除重复文件，展示重复文件组。
- **重命名规则**：按照指定规则重命名文件，保持文件名的一致性。
- **边处理边去重**：在移动文件前检查目标文件是否存在，避免重复移动。
- **处理日志**：实时显示处理过程、进度和报错信息。

**使用方式**：
- 通过GUI界面使用：打开"⚡ 批量自动化"标签页，选择源文件夹和目标文件夹，管理文件夹映射，然后点击"开始处理"按钮。
- 通过命令行提示：在命令行菜单中选择选项7，系统会提示此功能已集成到GUI界面中。

### 2. 重复文件删除

**功能描述**：检测并删除重复文件，支持多种去重方式。

**主要特点**：
- **多种去重方式**：支持按哈希值、文件名、文件大小和修改时间去重。
- **多线程处理**：使用多线程计算哈希值，提高处理速度。
- **重复文件预览**：在删除前预览重复文件，确保操作的准确性。
- **自定义保留规则**：支持保留第一个、最后一个或最大的文件。

### 3. 批量重命名

**功能描述**：按照指定规则批量重命名文件。

**主要特点**：
- **多种命名规则**：支持自定义命名规则，包括前缀、后缀、时间戳等。
- **拼音转换**：自动将中文转换为拼音，方便国际化。
- **序号管理**：支持自定义起始序号和增量。
- **实时预览**：在重命名前预览新文件名，确保命名的正确性。

## 安装说明

### 环境要求

- Python 3.7+
- tkinter（Python标准库）
- 其他依赖包（见requirements.txt）

### 安装步骤

1. 克隆或下载项目到本地
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行主程序：
   ```bash
   python main.py
   ```

## 使用指南

### 批量自动化使用步骤

1. **选择文件夹**：
   - 点击"浏览"按钮选择源文件夹（包含待处理文件的文件夹）。
   - 点击"浏览"按钮选择目标文件夹（处理后文件的保存位置）。

2. **管理文件夹映射**：
   - 查看默认映射：程序会加载默认的文件夹映射。
   - 添加映射：点击"添加映射"按钮，输入源文件夹和目标文件夹名称。
   - 编辑映射：选择现有映射，点击"编辑映射"按钮修改。
   - 删除映射：选择现有映射，点击"删除映射"按钮删除。
   - 保存映射：点击"保存映射"按钮保存更改。

3. **开始处理**：
   - 点击"开始处理"按钮开始批量处理文件。
   - 处理过程中，日志区域会显示处理进度和结果。

4. **预览处理**：
   - 点击"预览"按钮可以预览处理结果，而不实际执行操作。

### 重复文件删除使用步骤

1. **选择文件夹**：选择要检查重复文件的文件夹。
2. **选择去重方式**：选择按哈希值、文件名、文件大小或修改时间去重。
3. **设置保留规则**：选择保留第一个、最后一个或最大的文件。
4. **预览重复文件**：点击"预览重复文件"按钮查看重复文件。
5. **删除重复文件**：点击"删除重复文件"按钮删除重复文件。

### 批量重命名使用步骤

1. **选择文件夹**：选择要重命名文件的文件夹。
2. **设置参数**：
   - 输入中文名称（用于生成拼音）。
   - 设置起始序号和增量。
   - 选择命名规则。
3. **预览重命名**：点击"预览重命名"按钮查看新文件名。
4. **执行重命名**：点击"执行重命名"按钮执行重命名操作。

## 配置说明

### 文件夹映射配置

文件夹映射存储在 `config/folder_mapping.json` 文件中，格式为 JSON：

```json
{
  "源文件夹名称": "目标文件夹名称",
  "陆雪琪": "L_陆雪琪",
  "云望舒": "Y_云望舒"
}
```

用户可以通过 GUI 界面管理映射，也可以直接编辑此文件。

### 日志配置

日志文件存储在 `logs` 目录中，包含处理过程的详细信息。

## 常见问题

1. **Q: 处理过程中出现错误怎么办？**
   A: 查看日志区域的错误信息，根据错误提示进行排查。

2. **Q: 如何添加新的文件夹映射？**
   A: 在批量自动化面板中点击"添加映射"按钮，输入源文件夹和目标文件夹名称。

3. **Q: 去重后文件没有被删除怎么办？**
   A: 检查是否有足够的权限，或者文件是否被其他程序占用。

4. **Q: 重命名后的文件格式不符合预期怎么办？**
   A: 检查命名规则设置，确保规则正确。

5. **Q: 程序运行缓慢怎么办？**
   A: 对于大量文件的处理，可能会需要较长时间，请耐心等待。

## 注意事项

- **备份重要文件**：在执行批量操作前，请备份重要文件，以防意外发生。
- **权限问题**：确保程序有足够的权限访问和修改文件。
- **文件占用**：确保待处理的文件没有被其他程序占用。
- **存储空间**：确保目标文件夹有足够的存储空间。
