# AI文件管理工具使用指南

## 📚 项目概述

AI文件管理工具是一款功能强大的文件管理工具，专为提高文件管理效率而设计。它提供了多种实用功能，包括文件夹批量创建、文件批量重命名、重复文件删除、文件信息导出到Excel以及文件夹结构分析等。

### 主要功能特点

- **批量创建文件夹** - 根据列表批量创建文件夹，自动添加拼音首字母前缀
- **批量重命名文件** - 智能重命名文件，支持中文转拼音，自定义命名规则
- **删除重复文件** - 基于多种方式检测重复文件，安全删除
- **导出Excel清单** - 将文件信息导出到Excel表格，包含详细信息
- **分析文件夹信息** - 分析文件夹结构和文件分布，生成详细报告
- **直观的GUI界面** - 现代化的图形用户界面，操作简单直观

   ```bash
   pip install -r requirements.txt
   ```
4. **启动程序** - 运行主程序

## 🔧 功能详解

### 1. 批量创建文件夹

**功能说明**：根据输入的文件夹名称列表，批量创建文件夹，并自动添加拼音首字母前缀。

**使用步骤**：

1. **选择文件夹** - 在左侧选项卡中点击 "📁 文件夹创建"
2. **设置父路径** - 点击 "浏览" 按钮选择父文件夹路径
3. **输入文件夹名称** - 在文本框中输入文件夹名称，每行一个
4. **开始创建** - 点击 "创建" 按钮开始创建文件夹
5. **查看结果** - 状态栏会显示创建结果

**示例**：
- 输入：`国漫`
- 结果：创建文件夹 `G_国漫`

### 2. 批量重命名文件

**功能说明**：批量重命名文件夹中的文件，支持中文转拼音，自定义命名规则。

**使用步骤**：

1. **选择文件夹** - 在左侧选项卡中点击 "✏️ 文件重命名"
2. **设置参数**：
   - 选择要重命名的文件夹
   - 输入中文名称（用于生成拼音）
   - 选择命名规则
3. **预览** - 点击 "预览" 按钮查看重命名效果
4. **开始重命名** - 点击 "重命名" 按钮开始重命名

**命名规则变量**：
- `{pinyin_name}` - 拼音名称
- `{index}` - 文件序号
- `{timestamp}` - 时间戳
- `{type}` - 文件类型
- `{chinese_name}` - 中文名称

### 3. 删除重复文件

**功能说明**：检测并删除文件夹中的重复文件，支持多种检测方式和递归扫描选项。

**使用步骤**：

1. **选择文件夹** - 在左侧选项卡中点击 "🗑️ 文件去重"
2. **设置参数**：
   - 选择要扫描的文件夹
   - 选择去重方式（名称、大小、修改时间、哈希值）
   - 选择是否递归子文件夹（默认勾选）
3. **扫描** - 点击 "扫描" 按钮开始扫描重复文件
4. **删除** - 点击 "删除" 按钮删除重复文件

**去重方式说明**：
- **名称** - 根据文件名检测
- **大小** - 根据文件大小检测
- **修改时间** - 根据文件修改时间检测
- **哈希值** - 根据文件内容哈希值检测（最准确）

### 4. 导出Excel清单

**功能说明**：将文件夹中的文件信息导出到Excel表格，包含详细信息。

**使用步骤**：

1. **选择文件夹** - 在左侧选项卡中点击 "📊 Excel导出"
2. **设置参数**：
   - 选择要导出的文件夹
   - 输入导出名称
   - 选择是否递归子文件夹
3. **导出** - 点击 "导出" 按钮开始导出
4. **查看结果** - 导出完成后会显示导出文件的位置

**导出信息**：
- 文件名
- 文件类型
- 文件大小
- 创建时间
- 修改时间
- 文件路径

### 5. 分析文件夹信息

**功能说明**：分析文件夹结构和文件分布，生成详细的分析报告。

**使用步骤**：

1. **选择文件夹** - 在左侧选项卡中点击 "📋 文件夹信息"
2. **设置参数**：
   - 选择要分析的文件夹
   - 选择是否递归子文件夹
3. **分析** - 点击 "分析" 按钮开始分析
4. **查看结果** - 分析完成后会显示详细报告

**分析内容**：
- 文件总数
- 文件夹总数
- 总大小
- 文件类型分布
- 子文件夹信息

## 💡 常见问题

### Q: 为什么创建文件夹时没有添加拼音首字母？

**A**: 请检查以下几点：
- 确保输入的是中文名称
- 确保使用的是GUI界面或正确调用了 `create_single_folder` 函数
- 检查是否有错误信息显示

### Q: 文件重命名时出现乱码怎么办？

**A**: 这可能是由于编码问题导致的，请确保：
- 使用的是Windows系统默认编码
- Python版本为3.8或更高
- 文件名中不包含特殊字符

### Q: 删除重复文件时会误删文件吗？

**A**: 不会，程序会：
- 保留第一个文件，只删除后续的重复文件
- 在删除前会显示预览
- 提供多种检测方式，可根据需要选择

### Q: Excel导出失败怎么办？

**A**: 请检查：
- 文件夹路径是否正确
- 是否有足够的权限
- 文件夹是否包含太多文件（可能导致内存不足）

### Q: 程序启动时出现依赖错误怎么办？

**A**: 请尝试：
- 确保网络连接正常
- 手动安装依赖：`pip install -r requirements.txt`
- 检查Python版本是否为3.8或更高

## 🛠️ 故障排除

### 启动失败

**症状**：程序无法启动，显示错误信息

**解决方案**：
1. 检查Python是否正确安装
2. 检查依赖是否完整安装
3. 查看错误信息，根据提示解决问题
4. 尝试重新安装依赖

### 功能执行失败

**症状**：执行功能时出现错误

**解决方案**：
1. 检查输入参数是否正确
2. 检查文件权限是否足够
3. 检查文件路径是否存在
4. 查看错误信息，根据提示解决问题

### 依赖安装失败

**症状**：首次运行时依赖安装失败

**解决方案**：
1. 检查网络连接
2. 尝试使用国内镜像源：
   ```bash
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/
   ```
3. 手动安装失败的依赖包
