# AI文件管理工具
## 🚀 快速启动
### 方法1：双击启动（推荐）
双击运行 `start.bat` 文件，它会自动：
- 首次运行时安装所有依赖
- 后续运行时检查依赖状态
- 直接启动程序
### 方法2：命令行启动
```bash
# 安装依赖（仅首次需要）
pip install -r requirements.txt
# 启动程序
python main.py
```
## 📦 依赖管理
项目依赖记录在 `requirements.txt` 文件中，包括：
- pypinyin: 中文转拼音
- pandas: 数据处理
- openpyxl: Excel文件处理
- opencv-python: 图像处理
- Pillow: 图像处理
- scikit-image: 图像相似度计算
- librosa: 音频处理
- numpy: 数值计算
- scipy: 科学计算
## 🛠️ 功能特性
1. **批量创建文件夹** - 根据列表批量创建文件夹
2. **批量重命名文件** - 智能重命名文件，支持中文转拼音
3. **删除重复文件** - 基于MD5哈希值检测重复文件
4. **导出Excel清单** - 将文件信息导出到Excel表格
## 📁 项目结构
```
AI文件管理工具/
├── main.py                 # 主程序入口
├── start.bat               # 智能启动器（推荐使用）
├── requirements.txt        # 依赖清单
├── folder_creator.py       # 文件夹创建模块
├── file_renamer.py         # 文件重命名模块
├── duplicate_remover.py    # 文件去重模块
├── excel_exporter.py       # Excel导出模块
├── check_deps.py           # 依赖检查脚本
└── README.md               # 说明文档
```
## ⚠️ 注意事项
1. 首次运行会自动安装依赖，需要联网
2. 如果遇到权限问题，请以管理员身份运行
3. 删除 `.installed` 文件可以强制重新安装依赖
4. 支持Windows系统，需要Python 3.8+
## 🆘 故障排除
### 启动失败
- 检查Python是否安装（运行 `python --version`）
- 检查依赖是否完整（运行 `python check_deps.py`）
- 查看错误信息并搜索解决方案
### 依赖安装失败
- 检查网络连接
- 尝试使用国内镜像源：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/`
- 手动安装失败的包
