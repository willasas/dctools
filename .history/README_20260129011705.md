# AI文件管理工具

## 🚀 快速启动

### 方法1：双击启动（推荐）
双击运行 `start.bat` 文件，它会自动：
- 首次运行时安装所有依赖
- 后续运行时检查依赖状态
- 直接启动程序

### 方法2：命令行启动
```bash
# 安装依赖（仅首次需要）
pip install -r requirements.txt
# 启动程序
python main.py
```

## 📦 依赖管理

项目依赖记录在 `requirements.txt` 文件中，包括：
- pypinyin: 中文转拼音
- pandas: 数据处理
- openpyxl: Excel文件处理
- numpy: 数值计算
- scipy: 科学计算

可选依赖：
- opencv-python: 图像处理
- Pillow: 图像处理
- scikit-image: 图像相似度计算
- librosa: 音频处理

## 🛠️ 功能特性

1. **批量创建文件夹** - 根据列表批量创建文件夹
2. **批量重命名文件** - 智能重命名文件，支持中文转拼音
3. **删除重复文件** - 基于MD5哈希值检测重复文件
4. **导出Excel清单** - 将文件信息导出到Excel表格
5. **分析文件夹信息** - 分析文件夹结构和文件分布
6. **GUI界面** - 可视化操作界面，更直观易用

## ⚠️ 注意事项

1. 首次运行会自动安装依赖，需要联网
2. 如果遇到权限问题，请以管理员身份运行
3. 删除 `.installed` 文件可以强制重新安装依赖
4. 支持Windows系统，需要Python 3.8+
5. 分析大型文件夹可能需要一些时间

## 🆘 故障排除

### 启动失败
- 检查Python是否安装（运行 `python --version`）
- 检查依赖是否完整（运行 `python check_deps.py`）
- 查看错误信息并搜索解决方案

### 依赖安装失败
- 检查网络连接
- 尝试使用国内镜像源：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/`
- 手动安装失败的包

### 功能使用失败
- 检查文件夹路径是否正确
- 检查文件权限
- 对于大型文件夹，耐心等待操作完成
